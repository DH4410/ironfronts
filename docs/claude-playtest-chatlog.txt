-----------------

- Capture a screenshot at every meaningful phase or state change.
- After every screenshot, record what is clear, unclear, broken, stretched,

- Check menu flow, country selection, map readability, army movement, unit and
  building presentation, production, resource collection, diplomacy, combat,
  retreat/split/stop/extract actions, notifications, victory/defeat, and the
  final return-to-menu state.
- Never overwrite the real campaign save while preparing QA fixtures. Keep all
  playtest changes on the active feature branch and record the branch/commit.
- Claude Code should treat entries marked ACTION FOR CLAUDE as implementation
  requests, then append its response and verification evidence below them.

- Text: any clipping, overflow, ellipsis where the label should fit, overlap

- Console: skim the devtools console at least once per phase and paste any
  errors/warnings verbatim.

B. MENU / COUNTRY SELECT
- Menu buttons paint fully (no invisible/again-only-on-hover plates).
- Country picker: every selectable country shows a name, flag/colour and its
  stats; nothing is blank or "undefined". Confirm the map preview matches the
  country you picked.

C. MAP READABILITY
- Palette was just muted and borders made bolder — check the map still reads:
  province borders visible at all zooms, capital vs normal city distinguishable,
  ownership tint clear between 2+ factions without guessing, water vs land edge
  clean. Garrisoned cities are now selectable — confirm clicking one actually
  selects it and opens the right panel.
- Night was brightened — pan across a day/night terminator if visible and check
  nothing goes pure black or blows out, and that trees/props don't pop or
  flicker as light changes.
- Terrain: look for the "dome" look (flat ground lifting at the horizon), z-
  fighting on borders, seams between terrain tiles, forest clumps that look like
  a solid green blob or a grid pattern.

D. ARMY MOVEMENT & MODELS
- Select an army, order a long move: path line renders, chevrons point along the
  path, ETA text is sane ("7s" / "7m 12s" / "1h 03m"), unit count badge matches
  the panel.
- Unit models: tank & armoured-car hull/turret/gun should point along the travel
  direction (long axis = gun/tracks), not sideways. Infantry rifle/arms should
  face down-range. Marching gait (legs/arms/bob) should animate when moving and
  settle when stopped — check it doesn't freeze, T-pose, moonwalk, or vibrate
  when the army is idle or far from camera.
- Merge: move two friendly armies onto the same node — confirm they merge
  cleanly (one marker, summed counts) with no ghost/duplicate marker left.

E. UNIT & BUILDING PRESENTATION
- Open every unit portrait you can build. infantry/engineer/armoured-car/
  light-tank/medium-tank/artillery should have real art; militia / motorised /
  mechanised / paratrooper may fall back to a placeholder SVG — note which show
  what, and any white/opaque background box behind a portrait that should be
  transparent.
- Building/facility icons: barracks, tank plant, ordnance should have distinct
  art. Note any 0 A.D. / generic placeholder icon, any missing city/settlement
  icon slot, and any icon that is stretched, off-centre or the wrong one for its
  building.

F. PRODUCTION & RESOURCES
- Queue an item: thumbnail, name, ETA and an ×N badge for repeated identical
  orders all show correctly. Cancelling refunds/updates as expected.
- Resource counters tick up over time; province panel "extraction status" wording
  was just changed to plain language — confirm it reads clearly and matches the
  actual state (extracting / idle / blocked).

G. DIPLOMACY / NOTIFICATIONS
- Open diplomacy: every faction row is populated, stance is legible, actions have
  feedback. Trigger a notification (combat, production done, diplo) and check it
  is readable, dismissible, not stacking off-screen, not covering critical UI.

- Exercise retreat / split / stop / extract on an army: each button does what it
  says, updates the marker and panel, and can't leave the army in a stuck state
  (no orders, no marker, count 0 but still on map, etc.).

I. VICTORY / DEFEAT / RETURN
- Play to a win or loss if feasible. Check the end screen renders, stats are
