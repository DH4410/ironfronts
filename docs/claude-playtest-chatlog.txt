Purpose
-------
This is the shared handoff log for a complete human-style playthrough of one
Ironfronts game, from the main menu through a finished campaign. Codex records
what happens in the browser here so Claude Code can inspect the same evidence,
implement fixes, and report back without losing context.

Playtest contract
-----------------
- Play as a basic human: use the visible UI, make ordinary strategic choices,
  and avoid debug shortcuts unless a diagnostic check is explicitly labelled.
- Capture a screenshot at every meaningful phase or state change.
- After every screenshot, record what is clear, unclear, broken, stretched,
  missing, visually inconsistent, or unexpectedly animated.
- Check menu flow, country selection, map readability, army movement, unit and
  building presentation, production, resource collection, diplomacy, combat,
  retreat/split/stop/extract actions, notifications, victory/defeat, and the
  final return-to-menu state.
- Never overwrite the real campaign save while preparing QA fixtures. Keep all
  playtest changes on the active feature branch and record the branch/commit.
- Claude Code should treat entries marked ACTION FOR CLAUDE as implementation
  requests, then append its response and verification evidence below them.

  cleanly (one marker, summed counts) with no ghost/duplicate marker left.
